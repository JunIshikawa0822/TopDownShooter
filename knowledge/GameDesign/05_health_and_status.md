# 05. ヘルス・ダメージ・状態異常・ステータス・医療

## 1. 部位HP ✅

| 部位 | HP🟨 | 破壊（0）時 |
|---|---|---|
| 頭 | 35 | 即死 |
| 胸 | 85 | 即死 |
| 腹 | 70 | 以後のダメージが他部位へ拡散、空腹・水分の減りが速い❓ |
| 左腕 / 右腕 | 60 | 構え・リロードが遅い、拡散増、両腕で武器が持てない❓ |
| 左脚 / 右脚 | 65 | 走れない・移動が遅い、足を引きずる |

- `[HP-001]` ✅ プレイヤーは部位HP。🟨 敵は種類で選ぶ：人型＝部位HP、雑魚・動物・機械＝単一HP＋弱点倍率（負荷と作業量の節約）。P0
- `[HP-002]` 🟨 破壊済み部位へのダメージは残りの部位へ分配（係数 0.7 など）。頭・胸が 0 で死亡。P0
- `[HP-003]` 🟨 破壊部位は通常の回復薬では治らず、手術キットで「最大HPが減った状態」で復帰。P2
- `[HP-004]` 🟨 過剰ダメージ：部位HP を超えた分も分配。P1
- `[HP-005]` 🟨 自然回復：戦闘外でごくゆっくり❓（既定なし。スキル・拠点で解放）。

## 2. ダメージ計算の流れ 🟨 P0

```
命中（誰が・何で・どこに・どの方向から・距離）
 ① 部位の決定（当たった判定 or 抽選）
 ② 距離減衰
 ③ 防具判定：その部位を覆う防具があるか → 貫通判定（弾の貫通力 vs 防具クラス×残耐久）
     貫通   → ダメージ小減、防具耐久減
     非貫通 → 鈍的ダメージ（数%）のみ、防具耐久大きく減、ひるみ
 ④ ダメージ種別の耐性（物理/火/電気/毒/爆風…）とステータス補正
 ⑤ 部位倍率 → 部位HP へ適用 → 破壊・拡散
 ⑥ 状態異常の付与抽選（出血・骨折・炎上…）
 ⑦ 死亡判定 → 結果を通知（HUD・音・AI・統計・クエスト）
```

- `[DMG-001]` 各段階は差し替え・追加できる並びにする（モードや敵種で段を増減）。
- `[DMG-002]` ダメージ種別：物理(弾)・物理(刃)・鈍的・爆風・火・電気・毒・出血・落下・環境。🟦 `ElementType` を発展。
- `[DMG-003]` 結果には「どの段階で何が起きたか」を残す（貫通した/止めた/部位破壊/キル/ヘッドショット）。演出・統計・クエストが参照。
- `[DMG-004]` 🟨 防具：クラス 1〜6、覆う部位、耐久、材質（耐久の減り方・修理で最大値が減る量）、鈍的ダメージ率、移動・旋回・エルゴ・聴覚へのペナルティ。プレートの差し替え❓。P0（単純版）
- `[DMG-005]` 🟨 ヘルメット：跳弾確率、バイザー、ヘッドセット併用可否。P2
- `[DMG-006]` 🟨 ひるみ・よろけ：ダメージ量や部位で短い硬直。プレイヤーは照準が跳ねる。P1
- `[DMG-007]` 🟨 無敵・ダメージ無効区間（回避中❓、侵入直後、演出中）。P1
- `[DMG-008]` 🟨 キルの帰属：最後に当てた者＋出血など継続ダメージの付与者を覚える。P1

## 3. 状態異常 ✅

| 種別 | 効果 | 付与 | 解除 |
|---|---|---|---|
| 軽出血 | 部位からHPが漏れる | 被弾 | 包帯 |
| 重出血 | 速く漏れる、血痕が残る（AI が追う❓） | 被弾（高ダメージ/胴） | 止血帯・止血剤 |
| 骨折 | 腕：拡散増・構え遅い / 脚：走ると痛みダメージ | 被弾・落下 | 添え木 |
| 痛み | 画面の揺れ・ぼやけ、拡散増 | 部位破壊・骨折 | 鎮痛剤（効果時間中は無視） |
| 脳震盪/耳鳴り | 聴覚が効かない、画面のぶれ | 爆発・頭部被弾 | 時間 |
| 目潰し | 画面白飛び、AI は照準不可 | 閃光・ライト | 時間 |
| 炎上 | 継続ダメージ、移動で消える❓ | 焼夷 | 時間・水 |
| 毒/放射線 | 継続ダメージ・最大HP低下 | 環境・敵 | 解毒剤 |
| 疲労 | スタミナ 0。走れない・構えが揺れる | スタミナ切れ | 休む |
| 過重 | 移動・スタミナ回復低下、足音大 | 重量超過 | 荷を捨てる |
| 脱水/空腹❓ | 徐々に不利 | 時間 | 飲食 |
| 興奮剤（バフ） | 移動・回復・痛み無視など＋副作用 | 注射器 | 時間 |
| 制圧 | 拡散増・AI は頭を下げる | 至近弾 | 時間 |

- `[SE-001]` 🟨 状態異常は共通の枠で定義：対象（全身/部位）、持続（時間/永続/条件）、**重ね方**（上書き/時間延長/個数加算/強い方のみ/別枠）、周期効果、能力値補正、行動の制限（走れない等）、見た目。P0
- `[SE-002]` 🟨 🟦 `StatusEffectMode` の4分類（一時補正/即時変化/継続補正/周期変化）は「効果の部品」として残す。1つの状態異常は部品を複数持てる（例：興奮剤＝移動+補正＋終了後に疲労を付与）。P0
- `[SE-003]` 🟨 耐性・免疫・付与確率の補正（スキル・装備）。P2
- `[SE-004]` 🟨 状態は「タグ」でも表す（例：`状態.走行不可`）。行動側はタグを見るだけで、どの状態異常が原因かを知らない。P0
- `[SE-005]` 🟨 HUD に原因と残り時間、治療に必要な品のヒント。P1

## 5. ステータス（能力値）🟨

現行の2系統を**1つに統合**します。

- `[STAT-001]` 能力値＝「基礎値＋補正の集まり」。補正は出所（装備・状態異常・スキル・拠点・接辞・姿勢）を持ち、出所ごとに外せる。P0
- `[STAT-002]` 補正の種類と順序：①加算 → ②加算倍率（同種は足し合わせ：+10% と +20% = +30%）→ ③乗算倍率（掛け合わせ）→ ④上書き → ⑤下限・上限。🟦 現行の「(基礎+加算)×(1+倍率和)」を含む。P0
- `[STAT-003]` 能力値ごとに計算方法を差し替え可（🟦 `IStatCalculationStrategy` 継承）。例：反動は「低いほど良い」ので上限・下限の向きが逆。P1
- `[STAT-004]` キャラの能力値と**武器の能力値は同じ仕組み**（武器は自分の表を持ち、アタッチメントが補正の出所）。キャラ側の補正（スキル「反動制御」）が武器の最終値にも掛かる。P0
- `[STAT-005]` 能力値の識別は文字列の直書きをやめ、**定義済み ID** にする（誤字防止・スプレッドシートと照合）。P0
- `[STAT-006]` 一覧（初期案）：最大HP(部位別)、スタミナ最大/回復/消費、移動速度(歩/走/しゃがみ)、旋回速度、所持重量上限、足音音量、視界距離/角度、聴覚距離、反動制御、エルゴ補正、リロード速度、持ち替え速度、ADS 速度、治療速度、探索(漁り)速度、各ダメージ耐性、出血/骨折耐性、売買価格係数、経験値係数。

## 6. 医療・消耗品 🟨 P0〜P1

- `[MED-001]` 回復薬は「回数/残量」を持つ（例：救急キット 400 ポイント）。使用時間あり、移動で遅くなる/中断される。
- `[MED-002]` 対象部位：自動（最も危険な部位：重出血 > 破壊 > 低HP）＋手動選択（長押しで部位ホイール）。
- `[MED-003]` 効果は部品の組み合わせ：HP 回復、状態異常の解除、状態異常の付与（バフ・副作用）、リソース回復。
- `[MED-004]` 使用は行動の一種（入力バッファ・キャンセル窓の対象）。中断時は消費しない/途中まで消費を品ごとに。
- `[MED-005]` クイックスロットから即使用。使用中は武器を下ろす。
- `[MED-006]` 飲食❓、注射器（即効・副作用）、手術キット（破壊部位の復旧）。
