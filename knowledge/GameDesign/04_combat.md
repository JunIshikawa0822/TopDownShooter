## 2. 銃のパラメータ

🟦 既存：対応弾種、内蔵弾倉か、容量、発射方式、バースト数、RPM、初速、水平/垂直反動、基本拡散、連射拡散増加、最大拡散、リロード時間、エルゴノミクス、有効射程、重量、価格、ランク。

🟨 追加：

| パラメータ | 用途 |
|---|---|
| 精度(MOA 相当) と 拡散の回復速度 | 撃ち止めたときの収束 |
| 拡散係数（移動/しゃがみ/ADS/腰だめ） | 姿勢で変わる |
| 反動パターン（最初の数発の癖）＋ランダム幅 | 覚えて制御する楽しさ |
| 構え時間・持ち替え時間・スプリント復帰時間 | エルゴノミクスから算出 |
| 耐久（現在/最大）・故障率曲線 | ジャム、精度低下 |
| 発砲音量（m）・サプレッサー時 | AI の聴覚 |
| マズルフラッシュ規模 | 夜間の被発見 |
| 薬室の有無（+1発） | タクティカルリロード |
| 過熱❓ | LMG 用。P3 |
| 選択可能な発射方式の一覧 | セレクター |
| 移動速度係数・旋回速度係数 | 重い銃は鈍い |
| 片手/両手 | 盾・負傷時 |

## 3. 射撃の流れ 🟨

```
引き金入力 → 行動可否（切替中/リロード中/めり込み/スプリント復帰）→ 発射方式が「撃つ」と判断
 → 薬室に弾があるか（無ければ空撃ち）→ 故障判定 → 弾を1発取り出す
 → 拡散・反動を加えた方向を決定 → 弾丸生成（散弾は N 粒）→ 反動・拡散を加算
 → 音（AI へ）・演出の合図 → 次弾装填（給弾方式による）
```

- `[FIRE-001]` 🟦→🟨 セミ：1入力1発。バッファで連打を拾う。P0
- `[FIRE-002]` 🟦→🟨 バースト：1入力で N 発。途中で離しても撃ち切る❓/止まる を銃ごとに。重複起動しない。P0
- `[FIRE-003]` 🟦 フル：押下中、発射間隔ごと。フレームレートに依存しない（1フレームに2発出る RPM でも帳尻を合わせる）。P0
- `[FIRE-004]` 🟨 ポンプ/ボルト：撃つたびに操作時間。操作中は ADS が外れる❓。P1
- `[FIRE-005]` 🟨 チャージ：溜めて離すと発射（弓・レールガン）。P3
- `[FIRE-006]` 🟨 散弾：粒数・粒ごとの拡散・粒ごとのダメージ。スラグ弾は1粒。P0
- `[FIRE-007]` 🟨 故障（ジャム）：耐久が低いほど発生。種類（不発/排莢不良/給弾不良）ごとに解除操作と時間。❓入れるか（P2）
- `[FIRE-008]` 🟦 銃口めり込み：壁に銃口が入っていると撃てない → 🟨 銃を下げる姿勢にして見た目でも分かるように。P1
- `[FIRE-009]` 🟨 弾の発射位置：見た目は銃口から、**当たり判定は体の中心線から**始める（壁抜き・壁越し撃ち防止）。P0
- `[FIRE-010]` 🟨 味方撃ち・自爆：爆発は自分にも当たる。P1

## 4. 弾薬・マガジン・リロード

- `[AMMO-001]` 🟦 弾種区分（Light/Middle/Heavy）→ 🟨 口径（9x19, 5.56, 7.62, 12G…）へ細分化。銃・マガジン・弾は口径で適合。P1
- `[AMMO-002]` 🟦 弾ごとの性能：ダメージ・貫通力・トレーサー色・特殊効果。🟨 追加：防具ダメージ率、破片化率、跳弾率、初速係数、精度係数、反動係数、出血確率、亜音速（音量減）。P0
- `[AMMO-003]` 🟦 マガジンは実物アイテム（残弾を持つ）。🟨 **マガジン内に異なる弾を順番に詰められる**（上から順に撃つ）❓ 現行は1種類のみ。P2
- `[AMMO-004]` 🟨 リロードの種類：
  - タクティカル（残弾あり）：マガジン交換のみ。薬室の1発は残る。外したマガジンはリグへ戻す。
  - エンプティ（弾切れ）：交換＋薬室装填で長い。
  - クイック（R 2度押し🟨）：外したマガジンを**地面に落とす**代わりに速い。
  - 1発ずつ（ショットガン・リボルバー・内蔵弾倉）：1発ごとに区切り、いつでも中断して撃てる。
- `[AMMO-005]` 🟨 次に使うマガジンの選び方：リグ/ポケットから「残弾が最も多い」ものを自動選択。R 長押しで一覧から選ぶ。バックパック内は取り出しに追加時間 or 不可❓。P0
- `[AMMO-006]` 🟨 リロードは段階制（外す→取り出す→挿す→装填）。どの段階まで進んだかで中断時の状態が決まる。P0
- `[AMMO-007]` 🟨 残弾表示：正確な数字は出さず、マガジン確認で「満/ほぼ満/半分/少/空」。❓ 数字表示にするか（設定で切替を推奨）。P2
- `[AMMO-008]` 🟨 弾込め：インベントリでマガジンに弾をドラッグ。1発ごとに時間（レイド中のみ）。P1
- `[AMMO-009]` 🟦 デバッグ用「弾を消費しない」フラグ。

## 5. アタッチメント

- `[ATT-001]` 🟦 種類：グリップ/マガジン/ストック/マズル/スコープ。🟨 追加：ハンドガード、バレル、レール、レーザー/ライト、レシーバー、チャージングハンドル。P2
- `[ATT-002]` 🟦 入れ子スロット（部品が新しいスロットを生む）。🟨 適合は「種類」だけでなく「規格タグ」で判定（例：このハンドガードは M-LOK のグリップのみ）。競合（同時装着不可）も定義。P1
- `[ATT-003]` 🟦 補正値で銃の性能が変わる。🟨 必須部品（無いと撃てない）と任意部品の区別。P1
- `[ATT-004]` 🟨 機能付き部品：サプレッサー（音量・フラッシュ減）、ライト（照らす・目潰し・被発見）、レーザー（腰だめ精度・照準線表示）、スコープ（ADS 距離）。オン/オフ操作。P1
- `[ATT-005]` 🟨 見た目に反映（部品ごとの取り付け位置）。銃全体のインベントリサイズが部品で変わる。折りたたみストック。P2
- `[ATT-006]` 🟨 ビルドの保存・再現（プリセット）、足りない部品を商人から一括購入。P3

## 6. 弾道と命中 ✅（貫通・防具・跳弾）

- `[BAL-001]` 🟦 弾は実体として飛ぶ（即着弾ではない）。固定更新で前進、当たり判定は線。P0
- `[BAL-002]` 🟨 距離減衰：有効射程まで 100%、最大射程で下限％へ。P0
- `[BAL-003]` 🟨 重力・空気抵抗❓：見下ろし型では省略を推奨（投擲物のみ放物線）。
- `[BAL-004]` 🟨 **材質**：木・薄い金属・コンクリート・土・ガラス・肉体・防具板…ごとに「貫通抵抗／厚み換算／跳弾しやすさ／弾痕と音」。当たった物の材質を引く。P0
- `[BAL-005]` 🟨 **貫通**：弾の貫通力と材質×厚みを比べ、抜けたら貫通力・ダメージ・速度を減らして続行。抜けなければ停止。入射角が浅いほど厚み増。P0
- `[BAL-006]` 🟨 **跳弾**：浅い角度で硬い材質に当たると確率で反射。反射後は威力大幅減・回数上限。P1
- `[BAL-007]` 🟨 破片化：体内で砕けて追加ダメージ（弾種の確率）。P2
- `[BAL-008]` 🟨 命中部位：キャラの当たり判定を部位ごとに分ける。見下ろし型なので**高さ方向は抽選**も選択肢（頭 10%・胸 40% など姿勢で変わる表）❓ → 12章 Q6。
- `[BAL-009]` 🟨 遮蔽物越し：低い遮蔽（しゃがむと隠れる高さ）は、遮蔽に密着している側の射線だけ通す❓。P2
- `[BAL-010]` 🟨 至近弾：かすめた弾は「制圧」効果（AI の怯み・プレイヤーの画面効果）。P2
- `[BAL-011]` 🟨 弾が多くても重くならないこと（同時 500 発を目安）。P0

## 7. 近接 🟨 P1

- `[MEL-001]` 素早い近接（どの武器を持っていても V でナイフ/銃床）と、近接武器を構えた通常攻撃。
- `[MEL-002]` 攻撃は「予備動作→当たり判定あり→硬直」の3区間。コンボ（次段への受付窓）、溜め攻撃。
- `[MEL-003]` 当たり判定は扇/カプセル。壁越しに当たらない。1振りで同じ相手に1回。
- `[MEL-004]` スタミナ消費（🟦 定義あり）、ガード（🟦 `CanGuard`）❓、背後からの**ステルスキル**（気づいていない敵を一撃）。
- `[MEL-005]` 武器の耐久。

## 8. 投擲・爆発 🟨 P1

- `[THR-001]` 構え中は軌道と着地点を表示。投げる強さは長押し or カーソル距離。下手投げ（転がす）。
- `[THR-002]` 信管：時限（構え中に進む＝クッキング❓）/ 着発。壁で跳ね返る。
- `[THR-003]` 種類：破片（爆風＋破片弾）、閃光（視界・聴覚を奪う。向きと距離で強さ）、煙（視線を遮る＝AI も見えない）、焼夷（燃える地面）、おとり（音を出す）。
- `[THR-004]` 爆発：中心からの距離で減衰、遮蔽物の裏は防ぐ、破片は弾として飛ぶ（貫通計算を共用）。

## 9. 武器の持ち替え 🟨 P0

- `[SWP-001]` スロット：メイン1・メイン2・サイドアーム・近接。持ち替え時間＝しまう＋出す（エルゴノミクス）。サイドアームは速い。
- `[SWP-002]` 持ち替え中に別スロットを押したら最後の入力を採用。見た目のロード待ちで**古い武器が後から出ない**こと（現行 TODO）。
- `[SWP-003]` 床から拾って即装備、武器を捨てる、背中/ホルスターへの表示。
- `[SWP-004]` 敵も同じ武器・同じルールで撃つ（弾数・リロード・拡散）。
