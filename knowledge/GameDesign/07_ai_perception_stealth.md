# 07. 敵AI・知覚・視界制限・音・ステルス

## 1. プレイヤーの視界制限 ✅

- `[VIS-001]` 🟨 プレイヤーの**前方の扇形（例 110度）＋周囲の近距離円（例 3m）**の中で、かつ遮蔽物に遮られていない範囲だけ敵・アイテム・動く物が見える。地形は常に見える（暗く表示）。P0
- `[VIS-002]` 🟨 範囲外へ出た敵は少し残像を残して消える（最後に見た位置の影）。P1
- `[VIS-003]` 🟨 視界は装備・状態で変わる：ADS で狭く遠く、スコープ倍率、暗所・夜、ライト/暗視、煙、閃光、ヘルメットのバイザー。P1
- `[VIS-004]` 🟨 見えない敵の**音は方向つきで可視化**（足音の波紋、銃声の方向マーカー）。聴覚の能力値とヘッドセットで範囲拡大。P0
- `[VIS-005]` 🟨 ドア越し・窓越し・低い遮蔽越しの見え方。開いたドアは視線を通す。P1
- `[VIS-006]` 🟨 高低差：上の階・下の階は別レイヤーとして見えない。P2
- `[VIS-007]` 🟨 味方（将来の NPC 仲間❓）の視界共有。P3
- `[VIS-008]` 🟨 視界計算は敵の数に比例して重くならないこと（見える可能性のある対象だけ判定、数フレームに分散）。P0

## 2. 音 ✅

| 音源 | 大きさの目安 | 変化要因 |
|---|---|---|
| 足音 | 歩き 4m / 通常 10m / 走り 18m🟨 | 床材、しゃがみ、重量、スキル、雨 |
| 銃声 | 80〜150m | サプレッサー、亜音速弾、屋内 |
| 着弾・跳弾 | 15m | 材質 |
| リロード・装備操作・漁り | 5〜8m | — |
| ドア | 通常 12m / 静かに 3m / 蹴破り 30m | 開け方 |
| 爆発 | 200m | — |
| 声（敵の会話・叫び） | 15〜40m | — |
| ガラス・物を倒す | 10〜20m | — |

- `[SND-001]` 🟨 ゲーム上の「音」は、聞こえる音声とは別に**出来事として発行**（種類・位置・大きさ・出した者）。AI の聴覚と HUD の可視化が受け取る。P0
- `[SND-002]` 🟨 伝わり方：距離で減衰。壁で減衰（壁1枚ごとに係数）❓/ 経路距離で判定❓。まずは「直線距離＋間の壁の枚数」で開始。P0
- `[SND-003]` 🟨 AI は音の種類で反応を変える（足音=調べに行く、銃声=警戒して方向を向く、爆発=退避/集合）。P0
- `[SND-004]` 🟨 おとり：物を投げて音を立て、敵を誘導。P2

## 3. AI の知覚 🟨

- `[PER-001]` 感覚：**視覚**（扇形＋距離＋遮蔽。明るさ・相手の姿勢・動きで発見速度が変わる）、**聴覚**、**被弾**（撃たれた方向を知る）、**仲間からの伝達**、**死体発見**。P0
- `[PER-002]` 気づきは即時ではなくゲージで溜まる：未発見 → 違和感 → 捜索 → 発見（戦闘）→ 見失い → 捜索 → 警戒しつつ復帰。距離が近い・正面・走っているほど速く溜まる。P0
- `[PER-003]` 記憶：最後に見た位置・時刻・確信度。見失うと確信度が落ち、「最後の位置」へ向かって捜索。P0
- `[PER-004]` HUD：敵の頭上に気づきゲージ❓（視界内の敵のみ）。P1
- `[PER-005]` 明るさ❓：暗所は被発見距離が縮む。ライト点灯で伸びる。P3
- `[PER-006]` 知覚の更新は敵ごとに頻度を変える（近い敵は毎フレーム近く、遠い敵は間引く）。P1

## 4. ステルス ✅

- `[STL-001]` 🟨 しゃがみ移動・歩きで足音が小さく、被発見距離も縮む。P0
- `[STL-002]` 🟨 背後からのテイクダウン（未発見の人型のみ。時間がかかり無防備）。P1
- `[STL-003]` 🟨 サプレッサー：銃声の届く距離を大幅に縮める。完全無音ではない。P1
- `[STL-004]` 🟨 死体：仲間が見つけると警戒。死体を運んで隠す❓。P3
- `[STL-005]` 🟨 警報・増援：発見した敵が無線/警報装置へ走る → 妨害できる。P2
- `[STL-006]` 🟨 全体警戒レベル：エリア単位。上がると巡回が増える・扉を施錠。時間で下がる。P2
- `[STL-007]` 🟨 ライト・レーザーは敵にも見える。P2

## 5. 行動（HTN）🟦→🟨

🟦 複合タスク／基本タスク／メソッド（前提条件つきの分解）／プラン／実行役、という骨格がある。

- `[AI-001]` 🟨 AI が見る世界は「黒板」：型つきのキー（数値・真偽・位置・対象）で、知覚や自分の状態が書き込む。🟦 `SelfState` の固定フィールドを置き換え、敵種ごとにキーを足せるように。P0
- `[AI-002]` 🟨 再計画のきっかけ：一定間隔ではなく、**関係するキーが変わったとき**／現タスクの失敗時／より優先度の高い計画が立ったとき。実行中タスクはむやみに破棄しない。P0
- `[AI-003]` 🟨 行動部品（オペレーター）：移動（地点/対象/遮蔽へ）、向く、照準、射撃（バースト長・制圧射撃）、リロード、遮蔽に入る/顔を出す、捜索、巡回、待機、逃走、回復、投擲、近接、ドアを開ける、警報を鳴らす、仲間を呼ぶ、漁る❓。P0〜P2
- `[AI-004]` 🟨 AI は**プレイヤーと同じコマンド**を出して体を動かす（同じ武器・同じリロード・同じ拡散）。命中率は「照準のぶれ・反応遅れ」で調整し、弾道は誤魔化さない。P0
- `[AI-005]` 🟨 戦術位置の選定：候補点（遮蔽・高所・側面）を採点（射線が通る/遮蔽がある/味方と離れる/距離が適正）。P1
- `[AI-006]` 🟨 遮蔽：マップに遮蔽点を置く（自動生成＋手置き）。高さ（低/高）と向き。P1
- `[AI-007]` 🟨 分隊：役割（突撃・援護・側面・狙撃）、同時に撃つ人数の制限（攻撃トークン）、情報共有、リーダー死亡で士気低下。P2
- `[AI-008]` 🟨 士気・性格：被害・劣勢で退く/降伏しない/突っ込む。敵種データ。P2
- `[AI-009]` 🟨 難度は「反応時間・照準精度・視野・連携」で調整（HP を増やさない）。P1
- `[AI-010]` 🟨 負荷：計画は1フレームに数体まで（順番待ち）。遠い敵は簡易化、画面外遠方は停止/休眠。P1
- `[AI-011]` 🟨 デバッグ表示：現在のプラン、黒板、視界・聴覚範囲、気づきゲージ、選んだ位置の採点。P1

## 6. 敵の種類（案）🟨

| 種類 | 特徴 | 優先 |
|---|---|---|
| 略奪者（雑兵） | 低装備、巡回、音に寄る、練度低 | P0 |
| 武装兵 | 防具・良い弾、遮蔽を使う、分隊行動 | P1 |
| 狙撃手 | 高所・遠距離、位置を変える、スコープの反射光で気づける | P2 |
| 突撃型 | 近接/ショットガンで詰める、足が速い | P1 |
| ボス＋護衛 | 固有装備・固有行動、エリア固定、確率出現 | P2 |
| 動物/感染体❓ | 聴覚が鋭い・近接のみ（世界観次第） | P3 |
| 機械（タレット・ドローン） | 単一HP、弱点、電源を切れる | P3 |
| 中立/商人 NPC❓ | 撃たなければ敵対しない | P3 |

## 7. 敵の配置 🟨

- `[SPN-001]` 配置点＋巡回路＋持ち場。レイドごとに抽選（必ず/確率/グループ）。P0
- `[SPN-002]` 増援：時間経過・警報・大きな音で湧く。プレイヤーの視界内・至近には湧かない。P1
- `[SPN-003]` 総数の予算（同時に生きている数の上限）と、マップ区画ごとの密度。P1
- `[SPN-004]` 敵の装備はロードアウト表から抽選（武器・防具・弾・所持品＝そのまま戦利品）。P0
