## 1. 世界観の仮置き（Q2 への提案）🟨

**封鎖都市「ヴェルニ」**。化学プラント事故で封鎖された近未来の工業都市。政府は壁を築いて撤退し、中には4つの勢力が残った。
プレイヤーは壁の外の闇市に雇われた「回収屋」。壁の中から物を持ち帰って稼ぐ。

| 勢力 | 立場 | 装備の傾向 |
|---|---|---|
| ハゲタカ（略奪者） | 取り残された住民・犯罪者 | 旧式・粗悪・混成 |
| ガーディアン社残党（元警備会社） | 施設を占拠する武装集団 | 西側系・防具あり・連携 |
| 封鎖軍（壁の守備隊の離反部隊） | 港と検問所を支配 | 東側系・狙撃・重火器 |
| 灰の子ら（事故後に生まれた教団） | 汚染区域に住む | 近接・興奮剤・罠・ガスマスク |

- 現代〜近未来の実銃ベース。属性弾（火・電気）は**特殊弾・投擲物・環境**として最小限に入れる（焼夷散弾、テーザー、ガス）。
- 「汚染」が世界の固有要素：ガス地帯・汚染水・変異はしないが正気を失った住民（P3）。

## 3. ダメージ計算式

### 3.1 距離減衰
```
距離比 r = 距離 / 有効射程
r ≤ 1.0        → ×1.00
1.0 < r ≤ 2.0  → ×(1.00 − 0.35×(r−1))   … 有効射程の2倍で 65%
r > 2.0（最大射程 = 有効射程×2.5 で消滅）→ ×0.65
貫通力も同じ曲線の半分の傾きで落ちる（2倍で −17%）
```

### 3.2 防具の貫通判定
```
防具の実効値 E = 防具クラス×10 × (0.6 + 0.4×耐久率)
差 d = 弾の貫通力 − E
貫通確率 P = clamp( (d + 15) / 25 , 0.02 , 0.95 )
   d ≥ +9 でほぼ確定貫通 / d = −2.5 で50% / d ≤ −15 でほぼ止まる
```
| 結果 | 体へのダメージ | 防具耐久の減り |
|---|---|---|
| 貫通 | ダメージ × (0.92 − 0.02×クラス) | ダメージ × 防具ダメージ率 × 0.10 × 材質係数 |
| 非貫通 | ダメージ × 鈍的率（防具ごと 8〜25%）※その部位へ | ダメージ × 防具ダメージ率 × 0.18 × 材質係数 |

- 耐久が 0 の防具は無いものとして扱う。
- 材質係数：アラミド 1.0 / UHMWPE 0.9 / 鋼 0.55 / チタン 0.7 / セラミック 1.6。
- 非貫通でも「ひるみ値」は入る（撃たれ続けると照準が跳ねる）。

### 3.3 遮蔽物の貫通
```
必要貫通力 = 材質抵抗 × 厚み(cm) / cos(入射角)   （入射角は最大75度で頭打ち）
貫通力 ≥ 必要値 → 貫通。残り貫通力 = 貫通力 − 必要値、ダメージ × (0.9 − 必要値/貫通力×0.5)
```
| 材質 | 抵抗/cm | 例（厚み→必要値） | 跳弾率（浅角時） |
|---|---|---|---|
| ガラス | 0.5 | 窓 1cm → 0.5 | 0% |
| 石膏ボード・薄板 | 1.0 | 室内壁 10cm → 10 | 0% |
| 木 | 1.6 | ドア 4cm → 6 / 木箱 → 6 | 5% |
| 薄い鉄板 | 9 | 車のドア 0.3cm×2 → 5 / ロッカー → 3 | 30% |
| 土嚢・土 | 1.2 | 土嚢 40cm → 48 | 0% |
| レンガ | 3.0 | 壁 20cm → 60 | 15% |
| コンクリート | 5.0 | 壁 20cm → 100（事実上不可）/ 柱 | 35% |
| 厚い鋼 | 25 | コンテナ壁 0.2cm → 5 / 装甲板 2cm → 50 | 45% |
| 肉体 | — | 貫通力 20 以上で体を抜け、後ろへ 50% の威力 | — |

→ **室内壁と木のドアはほぼ全弾が抜く／車とロッカーは拳銃弾を止めライフル弾は抜く／レンガはAP弾だけ／コンクリートは安全**、という覚えやすい4段階にする。

### 3.4 跳弾
- 入射角（面からの角度）が 20度未満、かつ材質の跳弾率×弾の跳弾係数の抽選に成功で反射。威力 ×0.45、貫通力 ×0.5、最大1回。

### 3.5 出血・骨折の付与（基本確率。弾の補正が乗る）
| 条件 | 軽出血 | 重出血 | 骨折 |
|---|---|---|---|
| 体に 20 以上のダメージ | 30% | — | — |
| 体に 50 以上のダメージ | 45% | 20% | 腕脚 12% |
| 非貫通（鈍的のみ） | 0% | 0% | 腕脚 5% |
| 部位破壊時 | 100% | 50% | 腕脚 100% |

## 4. 目標 TTK（倒すまでの時間）の考え方

「一発が重い」柱に従い、**防具が効いている間は硬く、効かなければ一瞬**にする。

| 状況 | 目標 |
|---|---|
| 無防備の胸に同格ライフル弾 | 2発（約0.1〜0.2秒） |
| 適正クラスの防具＋通常弾 | 胸 6〜10発（防具が削れて抜け始める）。脚・頭を狙う判断が生まれる |
| 適正クラスの防具＋AP弾 | 胸 3〜4発 |
| 頭（ヘルメット無し） | ほぼ全弾1発 |
| プレイヤーが雑兵（防具なし・粗悪弾）に撃たれる | クラス3を着ていれば胸 8発以上耐える |

→ プレイヤーの生存は「HPの多さ」ではなく **防具の選択・遮蔽・先に見つけること** に置く。敵の命中率は低め（07章 AI-009）にして、被弾そのものを減らす。

## 5. 精度・反動の基準

| 用語 | 単位 | 意味 |
|---|---|---|
| 精度 | 度 | 静止・構え時の最小の散り。0.3（狙撃銃）〜3.0（粗悪SMG） |
| 腰だめ係数 | 倍 | 構えていないときの散り。×2.5（拳銃）〜×5（狙撃銃） |
| 1発ごとの拡散増加 | 度 | 連射で広がる量。0.1〜0.6 |
| 回復 | 度/秒 | 撃ち止めたときに戻る速さ。4〜10 |
| 縦反動 | 点 | 1発で照準点が奥へ跳ねる量。100点 ≒ 射程方向へ 1.0m（距離20m時） |
| 横反動 | 点 | 左右のぶれ。100点 ≒ 0.6m |
| エルゴノミクス | 0〜100 | 構え時間 = 0.55 − エルゴ×0.004 秒、持ち替え = 0.9 − エルゴ×0.005 秒、スプリント復帰 = 0.40 − エルゴ×0.0025 秒 |

移動中 ×1.6、しゃがみ ×0.8、腕負傷 ×1.5、痛み ×1.3、制圧下 ×1.4（掛け合わせ）。
