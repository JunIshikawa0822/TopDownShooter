# 02. ビジョン・コアループ・ゲームモード

## 1. ビジョンと柱

🟨 一文：**「見えない角の向こうに怯えながら、持ち物を賭けて漁り、生きて帰る見下ろし型シューター」**

| 柱 | 意味 | 支える仕様 |
|---|---|---|
| 賭けている緊張 | 持ち込んだ装備と拾った戦利品は、帰るまで自分の物ではない | 死亡ロスト、脱出地点、保険、セキュアコンテナ |
| 情報が武器 | 見える範囲・聞こえる音・弾数の把握が勝敗を分ける | 視界制限、音、マガジン確認、敵の気づきゲージ |
| 一発が重い | 部位・防具・弾種で結果が大きく変わる | 部位HP、貫通、跳弾、状態異常 |
| 整える楽しさ | 荷物の詰め方、銃の組み方、拠点の育て方 | グリッドインベントリ、アタッチメント、拠点・クラフト |
| 触って気持ちいい | 入力が意図どおりに通る | 入力バッファ、キャンセル窓、エイム補助、ヒット演出 |

## 2. コアループ（脱出型）✅

```
拠点（準備）──出撃──▶ レイド（侵入→探索/戦闘→脱出判断）──脱出/死亡/時間切れ──▶ 精算 ──▶ 拠点
   ▲ 売買・クラフト・改造・クエスト受注                                        │
   └────────────────── 戦利品・経験値・クエスト進行 ◀──────────────────────────┘
```

- 秒のループ：見る・聞く → 位置取り → 撃つ/隠れる → リロード/治療。
- 分のループ：部屋を制圧 → 漁る（何を捨て何を持つか）→ 次へ行くか帰るかの判断。
- レイドのループ：装備を選ぶ → 出撃 → 生還/全ロス → 精算。
- 長期ループ：商人ランク・拠点・スキル・クエストで行ける場所と使える装備が広がる。

## 3. ゲームモード ✅（ルールは混在させない）

**モード＝ルールの束**。どのモードも同じ戦闘・アイテム・AI の上で動き、違うのは下表の「方針」だけ、という作りにします。
1つのレイドは必ず1つのモードに属し、方針は途中で変わりません。

| 方針 | 脱出型（メイン）✅ | ルーター型 ✅将来 | ローグライト型 ✅あってもよい |
|---|---|---|---|
| 持ち込み | スタッシュから自由に | スタッシュから（装備レベル制限あり🟨） | 固定の初期装備 or ドラフト🟨 |
| 死亡時 | 身に着けた物を全ロス（保険・セキュア除く） | ロストなし or 拾得物のみロスト❓ | ラン終了。全て失う |
| 持ち帰り | 脱出成功時のみ | ステージクリア時（途中帰還可❓） | 持ち帰らない（恒久通貨のみ） |
| 進行 | 商人・拠点・クエスト・スキル | アイテムレベル・レア度・ステージ解放 | 恒久アンロック、ラン内強化 |
| 勝利条件 | 脱出地点から生還 | ボス撃破/目標達成 | 最終層突破 |
| 時間制限 | あり（レイドタイマー） | なし or ステージごと❓ | なし🟨 |
| 敵の強さ | マップ固定＋ランダム | ステージ Tier でスケール | 層の深さでスケール |
| アイテム生成 | 固定アイテム＋ルートテーブル | 接辞（ランダム付与効果）つき | ラン専用プール |

- `[MODE-001]` ✅ モード定義は「持ち込み／死亡／持ち帰り／進行／脱出条件／難度／時間」の方針を1つずつ選んだデータ。P0（脱出型の1件）
- `[MODE-002]` ✅ プロファイル（スタッシュ・通貨・進行）は**モードごとに独立**。共有するのは設定・図鑑・実績など🟨。❓通貨やアイテムをモード間で移せるか（→ 12章 Q1）
- `[MODE-003]` 🟨 分割の見せ方：タイトル直後に「どのゲームを遊ぶか」を選ぶ（ゲーム内ゲーム）。拠点もモード別。P2
- `[MODE-004]` 🟨 モードごとに有効な機能を宣言（例：ローグライトでは商人・保険を無効）。無効な機能の UI は出さない。P2
- `[MODE-005]` 🟨 ルーター型の接辞：既存の `EnchantData` を発展させ、レア度に応じて 0〜N 個のランダム効果を付ける。脱出型では接辞なし固定品。P3
- `[MODE-006]` 🟨 ローグライト型：シード付き乱数でラン再現、層クリアごとに3択強化、死亡時に恒久通貨へ換算。P3

## 4. レイドの進行 🟨

| 段階 | 内容 |
|---|---|
| 準備 | マップ選択・時間帯・装備確認・保険。`[RAID-001]` P0 |
| ロード | マップ・ルート・敵配置を生成。出撃済みフラグを保存（強制終了＝行方不明扱い）`[RAID-002]` P1 |
| 侵入 | 複数のスポーン地点から1つ。侵入直後数秒の安全🟨 `[RAID-003]` P1 |
| 進行中 | タイマー減少。残り時間で脱出地点・敵の圧が変化🟨 `[RAID-004]` P1 |
| 脱出中 | 脱出地点で一定時間とどまる（カウントダウン。被弾・離脱で中断❓）`[RAID-005]` P0 |
| 終了 | 結果：生還 / 戦死(KIA) / 行方不明(MIA=時間切れ) / 走り抜け(Run-through=短時間・無戦果の生還)🟨 `[RAID-006]` P0 |
| 精算 | 持ち帰り品の確定、経験値、クエスト進行、保険返却の予約、統計画面 `[RAID-007]` P0 |

- `[RAID-010]` 🟨 「レイド内発見（FiR）」印：レイドで拾って生還した品にだけ付く。納品クエスト・高値売却の条件。P2
- `[RAID-011]` 🟨 セキュアコンテナ：死亡しても中身が残る小さな枠。入れられる種類に制限。P1
- `[RAID-012]` 🟨 保険：商人に払うと、ロストした装備が（敵に拾われなければ）一定時間後に返る。シングルなので「敵AIが漁る確率」で表現❓ P2
- `[RAID-013]` 🟨 動的イベント：補給物資の投下、ボス出現、停電、増援。レイドごとの抽選。P3
- `[RAID-014]` 🟨 時間帯・天候：夜は視界が狭く音が通る。雨は足音を隠す。P3
- `[RAID-015]` 🟨 難度スケール：プレイヤーの装備価値・レベルで敵の構成を微調整（オフにできる）。P3
- `[RAID-016]` 🟨 中断と再開：レイド中の中断セーブは無し（拠点でのみ保存）。❓途中保存の要否
- `[RAID-017]` 🟨 練習（オフライン）モード：ロストなし・報酬なしでマップを歩ける。P2

## 5. 脱出地点 🟨

| 種類 | 条件 |
|---|---|
| 常設 | いつでも使える |
| 抽選 | レイドごとに開いているか不明（近づくと分かる） |
| 有料 | 所持金を払う |
| 鍵・品 | 特定アイテムが必要（消費する/しない） |
| 条件付き | バックパック無し、指定重量以下、特定の敵を倒した後、電源を入れた後 |
| 時間窓 | 残り時間が一定範囲のときだけ |

`[EXT-001]` 脱出地点は「条件の組み合わせ」で定義。条件を満たさない理由を HUD に表示。P0（常設のみ）/ P2（その他）

## 6. 規模の目安 ❓

- 1レイド 15〜30分、マップ 3〜5枚、武器 20〜40、敵タイプ 6〜10 を仮置き（→ 12章 Q4）。
