# 06. アイテム・インベントリ・装備・ルート

## 1. アイテムの種類

🟦 定義済み区分：Weapon / Armor / Accessory / Attachment / Ammo / Throwable / Container / Medical / Food / Drink / Stimulant / Material / Valuable / Intel / KeyItem。

🟦 共通項目：ID、表示名、説明、ランク、重量、価格、スタック上限、種別、タグ2種、見た目（モデル・グリッド幅/高さ・アイコン・拾得音・使用音）。

- `[ITEM-001]` 🟨 アイテムの能力は**「特性」の組み合わせ**で表す（継承ではなく部品）。例：

| アイテム | 特性の組み合わせ |
|---|---|
| アサルトライフル | 武器(銃) + 耐久 + アタッチメント台座 |
| アーマードリグ | 防具 + 収納 + 耐久 |
| マガジン | アタッチメント + 弾倉 |
| 回数付きの鍵 | 鍵 + 使用回数 |
| 救急キット | 消耗品 + 残量 |
| 弾薬箱 | 収納（弾のみ）+ 開封で中身に変換❓ |
| ガンケース | 収納（武器のみ） |
| 貴重品 | （特性なし。売るだけ） |

- `[ITEM-002]` 🟨 特性一覧：スタック / 耐久 / 残量・回数 / 武器(銃・近接・投擲) / 弾薬 / 弾倉 / アタッチメント / アタッチメント台座 / 防具 / 収納 / 消耗品 / 鍵 / 装備可能(どの枠か) / 能力値補正 / クエスト品 / 設置物。P0
- `[ITEM-003]` 🟨 実体ごとの状態：GUID🟦、スタック数🟦、耐久、残量、レイド内発見印、保険印、調査済みか、接辞（ルーター型）、中身（収納・弾倉・台座は入れ子）。P0
- `[ITEM-004]` 🟨 タグ整理（🟦 2種の enum は名前と中身が逆）：
  - **素材タグ**（物としての性質）：可燃・導電・爆発性・浮く・金属・電子…
  - **用途タグ**（できること）：消費・装備・装填・投擲…は特性から自動で決まるので持たない。
  - 自由なタグ階層（`アイテム.弾薬.9x19` など）にして、フィルタ・クエスト・商人の買取条件・収納制限が同じ言葉で書けるようにする。P1
- `[ITEM-005]` 🟨 レア度（色）・ランク🟦。未調査アイテムは名前と性能が伏せられる❓（調査に時間）。P3
- `[ITEM-006]` 🟨 耐久：使うと減る。修理で回復するが最大値が下がる。耐久で価格・性能が変わる。P1
- `[ITEM-007]` 🟨 表示名・説明は翻訳キー（多言語）。P2

## 2. グリッドインベントリ（テトリス型）

🟦 コンテナ＝複数のグリッドブロック。配置・回転(0/90度)・空き自動探索・重量合計・GUID 検索。UI は枠の生成まで。

- `[INV-001]` 🟨 操作一覧（P0）：ドラッグ移動、回転(R)、スタックの結合・分割(Ctrl+ドラッグ/数量指定)、入れ替え、捨てる、装備/解除、使用、弾込め、アタッチメント着脱、調べる。
- `[INV-002]` 🟨 **すべての操作は「検証→実行」の1単位**。UI は「この操作をしたい」と依頼するだけで、可否と理由（重量超過・サイズ不足・種類制限・入れ子禁止）が返る。失敗時は何も変わらない。P0
- `[INV-003]` 🟨 ドラッグ中の表示：置ける=緑、置けない=赤、結合=青、入れ替え=黄。理由をツールチップ。P0
- `[INV-004]` 🟨 クイック操作：Ctrl+クリック=相手側へ自動移動、Alt+クリック=装備、中クリック=調べる、ダブルクリック=使用/開く、Shift+クリック=まとめ選択❓。P1
- `[INV-005]` 🟨 自動配置：大きい物から詰める、回転を許す、既存スタックを先に埋める。整頓ボタン。P1
- `[INV-006]` 🟨 収納の制限：入れられる種類（タグ）、入れ子の深さ、自分自身の中に入れない、収納の中身込みの重量。P0
- `[INV-007]` 🟨 収納を開く：バックパック内のポーチは別ウィンドウで開く。同時に複数。P1
- `[INV-008]` 🟨 **レイド中は操作に時間がかかる**：インベントリを開いても時間は止まらない（周囲の音は聞こえる・視界は狭まる❓）。P0
- `[INV-009]` 🟨 漁る（探索）：コンテナを開くと中身が1つずつ判明する（探索速度の能力値）。途中で閉じても進捗は残る。P1
- `[INV-010]` 🟨 重量：身に着けた物の合計で段階ペナルティ。🟦 加減の式を統一。P0
- `[INV-011]` 🟨 パッド操作：カーソル移動＋グリッドスナップ。P2
- `[INV-012]` 🟨 コンテキストメニュー：種類に応じた項目（使う/装備/弾を抜く/分解/捨てる/調べる/マガジンを空に）。P1
- `[INV-013]` 🟨 比較ツールチップ：装備中と性能差を表示。P2
- `[INV-014]` 🟨 フィルタ・検索・お気に入り（誤売却防止ロック）。スタッシュで有効。P2

## 3. 装備枠 🟨 P0

| 枠 | 入る物 | 備考 |
|---|---|---|
| メイン武器1 / 2 | 銃 | 背中に表示 |
| サイドアーム | 拳銃 | |
| 近接 | 近接武器 | 失わない設定も可❓ |
| ヘルメット / フェイスカバー / アイウェア❓ / ヘッドセット | 頭部装備 | ヘッドセット＝聴覚強化 |
| ボディアーマー | 防具 | アーマードリグと排他 |
| リグ | 収納 | マガジンはここからリロード |
| バックパック | 収納 | ここからは直接リロードできない |
| ポケット | 収納（固定 1x1 ×4） | 拡張はスキル❓ |
| セキュアコンテナ | 収納（制限付き） | 死亡でも残る |
| 特殊（腕章・ドッグタグ等）❓ | | |

🟦 装備ビューは枠10個を想定。

- `[EQP-001]` 装備枠は「受け入れ条件つきの1マス収納」。グリッド収納と同じ操作体系で扱う。
- `[EQP-002]` 装備の着脱で能力値補正・見た目・武器スロットが更新される。
- `[EQP-003]` クイックスロット（4〜0）：リグ・ポケット内のアイテムを割り当て。品が無くなったら同種を自動で繋ぎ直す。
- `[EQP-004]` ロードアウト保存：スタッシュから一括装備、不足は商人から購入❓。P2

## 4. ルート（戦利品）🟨

- `[LOOT-001]` ルートテーブル：重み付き抽選、入れ子テーブル、個数範囲、必ず出る枠、レア枠。条件（マップ Tier・クエスト進行・運の能力値）。P0
- `[LOOT-002]` 生成物の状態もランダム：耐久、残弾、付いているアタッチメント、スタック数。P1
- `[LOOT-003]` ルートの置き場所：コンテナ（木箱・金庫・ロッカー・PC・死体・デスボックス🟦）と床置き（固定スポーン点）。P0
- `[LOOT-004]` 鍵部屋・金庫：鍵アイテムが必要な高価値ルート。P1
- `[LOOT-005]` 敵の死体：装備していた物がそのまま入る（撃ち壊した防具は耐久が減っている）。P0
- `[LOOT-006]` 🟦 コンテナは ID ごとに1度だけ生成し、レイド中は中身を保持（開け直しても同じ）。P0
- `[LOOT-007]` 床のアイテム：近づくと名前表示、ハイライト（レア度色）。捨てた物は床に残る。P0
- `[LOOT-008]` 自分のデスボックス❓：シングルなので「次のレイドで回収できる」救済を入れるか（→ 12章 Q3）。
- `[LOOT-009]` 価値の目安表示：スロットあたり価格。P3
- `[LOOT-010]` 乱数はレイドのシードから系統別（ルート/敵配置/AI/演出）に分け、再現・検証可能に。P1

## 5. データ運用 🟦→🟨

- `[DATA-001]` 🟦 スプレッドシート→SO。🟨 特性ごとにシートを分け、アイテム ID で結合。P1
- `[DATA-002]` 🟨 インポート時検証：ID 重複、参照切れ、サイズ 0、適合する弾/マガジンが存在しない銃、価格 0、アイコン無し。P1
- `[DATA-003]` 🟨 全アイテムは ID で引ける目録に載る（セーブデータは ID だけを持つ）。ID は変更禁止、廃止は別名表で救済。P0
