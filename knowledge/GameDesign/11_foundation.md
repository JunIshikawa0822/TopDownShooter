# 11. 基盤：セーブ・データ・設定・デバッグ・品質

## 1. セーブ 🟨

- `[SAVE-001]` 保存単位：プロファイル（スロット）→ **モードごとの進行データ**（スタッシュ・装備・通貨・商人・拠点・クエスト・スキル・統計）＋共有データ（設定・図鑑・実績）。P0
- `[SAVE-002]` 保存の瞬間：拠点での操作のたび（自動）、出撃時、レイド終了時。レイド中は保存しない。P0
- `[SAVE-003]` 不正終了対策：出撃時に「レイド中」印と持ち込み品を記録。次回起動時に印が残っていれば行方不明扱い（装備ロスト）❓ 厳しすぎるなら「練習扱いで巻き戻し」も選べる。P1
- `[SAVE-004]` 壊れにくさ：一時ファイルへ書いてから差し替え、世代バックアップ、破損検出（ハッシュ）、読み込み失敗時は1つ前へ。P1
- `[SAVE-005]` 版の移行：データに版番号。古い版は順に変換。アイテム ID の改名表。P1
- `[SAVE-006]` セーブには定義の ID と実体の状態だけを書く（定義そのものは書かない）。P0
- `[SAVE-007]` クラウド保存（Steam 等）❓ P3

## 2. 設定 🟨 P0〜P1

- 映像（解像度・品質・フレーム上限・VSync・明るさ・揺れ）、音（10章）、操作（キー設定・感度・押下方式・エイム補助）、ゲームプレイ（残弾表示形式・自動リロード・HUD 要素）、補助（色覚・字幕）、言語。
- `[SET-001]` 設定はプロファイルと別に保存。即時反映、既定に戻す。

## 3. データ基盤 🟨

- `[DATA-010]` すべての定義（アイテム・敵・状態異常・能力値・レシピ・クエスト・ルート表・モード）は ID を持ち、目録から引ける。P0
- `[DATA-011]` 🟦 スプレッドシート取り込みを全定義へ拡大。検証つき。P1
- `[DATA-012]` バランス値は1か所（共通係数表）に集める：ダメージ係数、音量係数、価格係数、経験値曲線。P1
- `[DATA-013]` 起動時の定義読み込みは非同期（🟦 Addressables）。見た目は必要時にロードし、使い終わったら解放（参照数管理）。P0

## 4. 時間 🟨

- `[TIME-001]` ゲーム内時間は「全体の倍率 × 個別の倍率（🟦 プレイヤー個別スロー）」。演出・クールダウン・バースト間隔・状態異常はすべてこの時間で進む（実時間待ちを使わない）。P0
- `[TIME-002]` ポーズ：ゲーム時間のみ停止。UI・設定は動く。P0
- `[TIME-003]` ヒットストップ・スローは時間倍率の要求を積み重ねて管理（複数要求の最小値を採用、期限で自動解除）。P2

## 5. デバッグ・開発支援 🟨

| ID | 内容 | 優先 |
|---|---|---|
| `[DBG-001]` | デバッグメニュー：無敵、弾無限🟦、アイテム生成、敵生成、テレポート、時間倍率、状態異常付与、視界制限オフ | P0 |
| `[DBG-002]` | 可視化：弾道と貫通結果、当たり判定、音の届く範囲、AI の視界・プラン・黒板 | P1 |
| `[DBG-003]` | シード指定でレイド再現 | P1 |
| `[DBG-004]` | 試験場シーン：武器・防具・弾の組み合わせ試験（標的の部位別ダメージログ） | P1 |
| `[DBG-005]` | ログ：ダメージ計算の全段階、インベントリ操作の失敗理由 | P1 |
| `[DBG-006]` | 自動テスト：ルール部分（能力値・ダメージ・インベントリ配置・ルート抽選・HTN 計画）は画面なしで検査できること | P1 |
| `[DBG-007]` | バランス統計：武器別 TTK 表の自動出力 | P3 |

## 6. 性能目標 ❓

- 60fps（PC 中位）。同時：敵 30〜50 体（うち活動中 15）、弾 500、床アイテム 500 を仮置き。
- `[PERF-001]` 毎フレームのメモリ確保を出さない（弾・音・視界・UI 更新）。P1
- `[PERF-002]` 負荷の高い判定（視界・AI 計画・音の遮蔽）は数フレームへ分散。P1

## 7. プラットフォーム ❓

- PC（Steam）を主。パッド対応。コンソール・携帯機❓。
