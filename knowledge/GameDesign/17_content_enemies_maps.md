# 17. コンテンツ案：敵・ボス・マップ・レイドイベント

## 2. ボス

各マップに1体。出現率 30〜40%（レイド開始時に抽選。出現時は遠くで特有の音がする）。固有の落とし物あり。

| ボス | マップ | 構成 | 仕組み（＝攻略の鍵） | 固有の落とし物 |
|---|---|---|---|---|
| **肉屋** | 貨物ヤード（冷凍倉庫） | 本人（C5全身・S-12ドラム・HP×1.5）＋荒くれ4 | 鈍いが止まらない。**冷凍倉庫の扉を閉めて閉じ込める／天井のフックを撃ち落として下敷きにする**環境攻略あり。正面の撃ち合いは不利 | 肉屋の鍵束（ヤード全室）、S-12 特別仕様 |
| **管理人** | ブロック9 | 本人（軽装・MP-9A）＋罠だらけの最上階 | 戦わず逃げ回り、監視カメラでこちらの位置を見て罠と警備ドローンを起動する。**配電盤を落とすとカメラと罠が止まる** | マスターキー（ブロック9全室、20回） |
| **通信兵** | 港湾 | 本人（C4・KR-74）＋歩哨6＋迫撃砲支援 | 発見されると 20秒ごとにこちらの位置へ迫撃砲。**先に無線機を壊す or 本人を狙撃**で砲撃が止まる | 暗号表（次回レイドの敵配置を表示）、封鎖軍の認識票 |
| **博士** | 研究棟 | 本人は非戦闘。実験体（単一HP 900・近接・高速）を放つ | 実験体は銃でほぼ倒せない。**消火設備のガス・隔壁・高圧電流**の3つの設備に誘い込む。博士を先に確保すると実験体が止まる | 黒カード、実験体血清のレシピ |
| **幽霊** | 全マップ（低確率 8%） | 単独・熱線スコープつき AS ナイトジャー・発煙弾 | プレイヤーを**追跡する**側の敵。足音を消し、煙を焚いて撃ってくる。一定ダメージで撤退し、同じレイド内で再襲撃 | 熱線スコープ、幽霊の覆面 |

## 3. マップ

固定カメラ・手作り＋ランダム要素（Q15・Q16 の推奨案）。サイズは歩いて端から端までの秒数（通常移動）。

### ① 貨物ヤード（入門）

| 項目 | 内容 |
|---|---|
| 規模・時間 | 横断 90秒 / 25分 / 敵 14〜20（ハゲタカ中心） |
| 構成 | コンテナ置き場（迷路状・視界が短い）／管理棟（2階建て）／整備工場／冷凍倉庫（ボス）／線路 |
| 学べること | コンテナ＝薄い鋼（拳銃弾は止まり小銃弾は抜く）で**貫通の基本**を学ぶ。開けた線路は走ると撃たれる |
| 高価値 | 管理棟の金庫室（鍵）、封印コンテナ（バール or 鍵。3つのうち1つが当たり）、整備工場の工具 |
| 脱出 | 北ゲート（常設）／線路トンネル（常設・遠い）／作業車（₡5,000・1回限り）／下水口（バックパック不可） |
| 固有 | クレーン操作でコンテナを動かし近道/遮蔽を作る（大きな音） |

### ⑤ 地下鉄（暗闇・終盤/P3）

真っ暗。ライトを点ければ見えるが見つかる、暗視装置は扇が狭い。灰の子らの本拠地。汚染水・ガス。線路を列車（無人）が通る音で銃声を隠せる。

### マップ共通の仕掛け

| 仕掛け | 内容 |
|---|---|
| 侵入地点 | マップごとに 4〜6。脱出地点は侵入地点の反対側が開く（必ず横断させる） |
| 抽選の脱出地点 | 近づくと緑/赤の灯で分かる。地図の切れ端があれば開始時に分かる |
| 隠し収納 | 床下・通気口・偽の壁。知覚スキル or マルチツールで発見 |
| 警報装置 | 敵が鳴らすと増援。事前に配線を切れる |
| 照明 | 撃って消せる。配電盤で一括消灯 → 暗所ステルス |
| 可燃物・爆発物 | ドラム缶、ガスボンベ、燃料溜まり |
| 近道 | 鍵・ロープ・スレッジで開く経路。知識が増えるほど速く動ける |

## 4. レイド中のイベント（1レイドに 0〜2個を抽選）

| イベント | 内容 | 狙い |
|---|---|---|
| 補給投下 | 飛行音→発煙→着地。高価値の箱。敵も集まる | 危険と報酬の天秤 |
| 縄張り争い | 2勢力が交戦中。漁夫の利 or 巻き込まれる | 第三者として立ち回る |
| 掃討作戦 | 残り10分で封鎖軍の増援が端から掃討してくる | 早めの脱出を促す |
| 停電 | マップ全体が暗くなる（電子扉は開かない/開きっぱなし） | 暗所戦 |
| 汚染雲 | ガス地帯がゆっくり移動 | 経路の再考 |
| 同業者の救難 | 無線で助けを求める声。罠の場合あり | 選択 |
| 行商人 | 特定地点に出現 | 寄り道の動機 |
| 幽霊の狩り | ボス「幽霊」が出現 | 追われる緊張 |
| 賞金首 | 特定の敵に印。倒して認識票を持ち帰ると高額 | 目標の追加 |

## 5. 難度の上げ方（マップ内の危険度）

- 敵の数ではなく**「構成」**で上げる：雑兵だけ → 盾＋突入員 → 狙撃手＋機関銃手＋擲弾手（遮蔽に留まれない・出られない）。
- マップ中央・高価値区画ほど練度の高い敵を置き、外周は雑兵。プレイヤーが自分で危険度を選べる。

## 6. 最初のリリースの最小セット（提案）

マップ：貨物ヤード1枚（＋試験場）。敵：あさり屋・見張り・荒くれ・火付け・番犬＋警備員・突入員の7種。ボス：肉屋。イベント：補給投下・掃討作戦。
