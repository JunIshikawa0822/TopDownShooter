# TopDownShooter ゲームデザインメモ（索引）

このフォルダはゲームデザイナー用の仕様メモです。**決まったこと・実装済みのこと・提案・未決事項をすべてここに集約**し、
エンジニア側の設計（`Docs/Design/TopDownShooter.uml.json`）はこのメモを入力として作ります。

## 凡例

| 印 | 意味 |
|---|---|
| ✅ | 確定（ヒアリングで決定済み） |
| 🟦 | 実装済み（現行コードに存在。未完成・不具合ありを含む） |
| 🟨 | 提案（デザイナー案。未承認） |
| ❓ | 要確認（ヒアリングが必要） |
| P0〜P3 | 優先度。P0=コアループ成立に必須 / P1=製品として必要 / P2=深み / P3=余裕があれば |

仕様には `[分野-番号]` の ID を振っています（例 `[CMB-012]`）。UML のクラスメモから参照します。

## ヒアリングで確定したこと（要約）

- ✅ メインは**脱出型**（出撃 → 漁る・戦う → 脱出 → 拠点で整理）。
- ✅ 将来、**ルーターシューター的モード**（ステージに潜って装備を得て、より強いステージへ）を入れたい。
- ✅ **死ぬと最初から＋恒久アンロック引き継ぎ**のモード（ローグライト）もあってよい。
- ✅ **ルールは混在させない**。ステージごと、あるいはゲーム内でゲームを分けるなど、何らかの形で分割する。
- ✅ **シングルプレイ専用**。
- ✅ 戦闘・索敵は **部位HP・状態異常 / 貫通・防具・跳弾 / 視界制限 / 音・ステルス** をすべて入れる。
- ✅ メタは **スタッシュ・商人 / 拠点強化・クラフト / クエスト・タスク / スキル・成長** をすべて入れる。
- ✅ **オブジェクト配置型の拠点カスタム・拡張**もあってよい（優先度は低い）。
- ✅ 核は**脱出**。**銃である必要はなく「撃ち出す武器」**（魔法を連射する／魔法を撃ち出す銃）。射撃と近接を混ぜる。（第4回）
- ✅ 世界観は**銃と魔法が同格**、シリアス。**属性反応と環境利用**を手触りの拠り所にする。（第4回）
- ✅ 魔法（属性反応・詠唱/溜め/維持・召喚/設置・補助/変化）、戦技（固有技・派生・防御・構え）、カスタマイズ（部品・埋め込み・技の改造・ツリー）はすべて入りうる。（第3回）
- ✅ 乗り物・遠隔操作・銃座・仲間、組み替え生成・持ち越す世界・壁破壊・昼夜天候、能力・回避・運搬・操作の遊び、分岐会話・非敵対NPC・勢力・同業者AI はすべて入りうる。（第2回）
- ✅ **拠点の防衛・襲撃**が構想にある。（第4回）
