# 08. ワールド・インタラクト

## 1. マップ 🟨

- `[MAP-001]` 手作りマップ＋ランダム要素（ルート・敵・開閉する脱出地点・鍵部屋の中身・イベント）。❓自動生成の要否（ローグライト型で部屋の組み替え）。P0
- `[MAP-002]` 区画（エリア）：名前・危険度・ルートの質・BGM/環境音・警戒レベルの単位。P1
- `[MAP-003]` 屋内/屋外、多層階（階段・梯子）。階層ごとに表示を切替。P1
- `[MAP-004]` 地図アイテム/M キー：歩いた所が記録される❓、脱出地点の位置。P2
- `[MAP-005]` 床材・壁材：足音・着弾・貫通の材質（04章 BAL-004）。P0
- `[MAP-006]` 経路：敵用の移動可能領域。ドア・窓・乗り越えは特別な接続。P0

## 2. インタラクト 🟦→🟨

🟦 近くの対象を探して最寄りにボタン表示、F で実行。種別：Door / Lootable。

- `[INT-001]` 🟨 対象は**複数の選択肢**を出せる（例：ドア＝開ける/静かに開ける/蹴破る/鍵を使う）。F 短押し＝既定、長押し＝一覧。P0
- `[INT-002]` 🟨 選択肢ごとに条件（必要アイテム・状態）と所要時間（長押しゲージ／行動として実行）。できない理由も表示。P0
- `[INT-003]` 🟨 候補の選び方：距離×向き×視線が通るか。遮蔽越し・壁越しは不可。P1
- `[INT-004]` 🟨 実行中は行動の一種（移動で中断、被弾で中断❓）。P1
- `[INT-005]` 🟨 敵も同じ仕組みで扉・警報を使う。P1

| 対象 | 選択肢・仕様 | 優先 |
|---|---|---|
| ドア | 開閉、静かに、蹴破り（敵をよろけさせる）、施錠（鍵/カード/破壊）、覗く❓。開閉で視線・射線・音・経路が変わる | P0 |
| ルートコンテナ🟦 | 開く→探索→中身表示。種類ごとのテーブル | P0 |
| 死体・デスボックス🟦 | 装備と所持品 | P0 |
| 床のアイテム | 拾う（空きへ自動配置）、装備する、調べる | P0 |
| 脱出地点 | 入るとカウントダウン。条件表示 | P0 |
| スイッチ・発電機・端末 | 電源、扉の開放、警報、脱出地点の解放 | P2 |
| 梯子・乗り越え・窓 | 移動の接続。乗り越え中は無防備 | P2 |
| 据え置き武器 | 乗る/降りる | P3 |
| 罠（地雷・ワイヤー） | 発見（近く＋ゆっくり）、解除、設置 | P3 |
| クエスト対象 | 調べる、置く、マーカー設置 | P1 |
| 破壊可能物 | 窓ガラス、木箱、ドラム缶（爆発）、照明（撃って消す） | P2 |
| 遮蔽物 | 倒して遮蔽にする机❓ | P3 |

## 3. 環境ハザード 🟨 P2

- `[HAZ-001]` 火・ガス・放射線・電気・有刺鉄線・地雷原。範囲に入ると状態異常/ダメージ。防護装備で軽減。
- `[HAZ-002]` 水場：移動が遅い・音が大きい。❓
- `[HAZ-003]` 暗所：ライトが無いと視界が極端に狭い。

## 4. 物の状態の持続 🟨

- `[WLD-001]` レイド中に変えた物（開けたドア、空にした箱、倒した敵、落とした物、壊した照明）はレイド終了まで保持。P0
- `[WLD-002]` レイドをまたぐ持続は無し（毎回生成）。❓拠点・一部マップのみ持続させるか。
