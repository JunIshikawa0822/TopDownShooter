# 19. 設計を左右する要素の洗い出し（デザイナー × エンジニアの相談記録）

**このメモが、デザイナーからエンジニアへの主たる受け渡し資料です。**
目的は数値や個別コンテンツを決めることではなく、**「このゲームに出てくる（出てくるかもしれない）物・遊び・機能の“種類”」を出し切り、設計がどこを差し替え可能にしておくべきかを決める**こと。

進め方：エンジニアが「設計上ここが分かれ目になる」という問いを出し、デザイナーが要素を列挙して確度を付け、エンジニアが設計への要求にまとめる。

## 確度の付け方

| 確度 | 意味 | 設計での扱い |
|---|---|---|
| **A** | 入れる（確定・ほぼ確定） | 最初から作り込む |
| **B** | 入れたい（有力） | 作らないが、**足すだけで入る口を用意**しておく |
| **C** | かもしれない | 口は作らない。ただし**入れるときに既存を壊さない**ことだけ確認する |
| **×** | 入れない | 前提から外してよい（単純化に使う） |

確度はデザイナーの見立てです。**ここが違うと設計が変わるので、違っていたら直してください**（末尾に確認したい点をまとめています）。

## 問1. 「体を持って動くもの」は何種類あるか

> エンジニア：プレイヤーと敵を同じ `Actor` にした。人型以外が来たとき、部品の組み合わせで足りるか知りたい。

| 要素 | 確度 | 人型との違い（＝設計が吸収すべき差） |
|---|---|---|
| 人型（プレイヤー・敵・同業者AI） | A | 基準。部位HP・装備枠・インベントリ・武器 |
| 四足の動物（番犬） | A | 装備・インベントリ無し、単一HP、近接のみ、移動が速い |
| 固定の機械（銃座・監視カメラ） | B | 移動しない、向きに制限、電源で停止、正面だけ装甲 |
| 飛ぶ機械（ドローン） | B | 高さを持つ、経路が地面に縛られない、遮蔽を越える |
| 大型（ボス・実験体） | B | 体が大きい、部位が独自（弱点が露出する段階）、通常の計算で倒せない場合がある |
| 非戦闘の人（行商人・生存者・博士） | B | 会話できる、護衛対象になる、撃つと敵対する |
| 仲間（雇った傭兵・連れて行く犬） | C | プレイヤーの指示を受ける、持ち物を預けられる、死ぬと失う |
| 乗り物（車・ボート） | C | 人が乗る、乗員に被弾判定、燃料、轢く |
| プレイヤーが遠隔操作する物（偵察ドローン・ラジコン爆弾） | C | **操作対象が自分の体から一時的に移る** |
| 死体 | A | 動かないが、漁れる・見つかる・運べる（C）・証拠になる |
| 群れ（ネズミ・虫の大群） | × | 個体ではなく領域として扱う（ハザード扱いにする） |

**設計への要求**
- 体の部品は「全員が持つ物」を最小にする（位置・陣営・タグ・時計）。HP の持ち方、装備、インベントリ、移動方式、武器は**付け外しできる部品**。
- 移動方式は差し替え（歩行／固定／飛行／乗り物）。
- 「誰が操作するか」と「どの体か」を分離し、**操作対象の付け替え**（遠隔操作・乗り物・銃座に着く）を可能に。
- 体の大きさ・当たり判定の構成は定義データ。

## 問2. 「頭（誰が動かすか）」は何種類あるか

| 要素 | 確度 | メモ |
|---|---|---|
| プレイヤー入力 | A | KB/M、パッド |
| AI（HTN） | A | |
| 台本どおりの動き（演出・チュートリアルの案内役） | B | 「ここへ歩いてこの台詞」 |
| 指示を受ける AI（仲間への「待て・ついて来い・撃て」） | C | AI の上に命令が乗る |

## 問3. 「手に持って使う物」の使われ方は何通りあるか

> エンジニア：`IWeapon` を引き金の押下/解放/毎フレームで定義した。これで表せない使い方を知りたい。

| 使い方の型 | 例 | 確度 |
|---|---|---|
| 押すと1回 | セミオート、単発、リボルバー | A |
| 押している間くり返し | フルオート | A |
| 押すと決まった回数 | バースト | A |
| 1回ごとに手動操作を挟む | ポンプ、ボルト | A |
| 溜めて離す | 弓、溜め近接、投擲の強さ | B |
| 押している間ずっと出続ける | 火炎放射器、消火器、ビーム、懐中電灯で照らす | B |
| 構えて離す（軌道表示） | 手榴弾、榴弾発射器 | A |
| 振る（予備動作→判定→硬直、コンボ） | 近接 | A |
| 置く | 地雷、センサー、C4、バリケード | B |
| 構えているだけで効果 | 盾、双眼鏡、集音器 | B |
| 切り替える | 射撃モード、スコープ倍率、ライト/レーザー、折りたたみストック、消音器の着脱 | A |
| 第2の使い方 | アンダーバレル、二連の同時発射、銃床打撃、銃剣 | B |
| 遠隔で作動 | C4 の起爆、ドローン操作 | C |
| 対象を選んで使う | 鍵を扉に、治療を部位に/他人に、ピッキング | A（他人への使用は C） |
| 両手に1つずつ | 二丁拳銃、拳銃＋ライト、拳銃＋盾 | C |
| 設置式に「着く」 | 銃座、据え置き機関銃 | C |

**設計への要求**
- 入力を「主操作・副操作・切替・リロード」の**複数の口**として受ける（引き金1本では足りない）。
- 「出続ける」型のために、弾を出さない**継続的な効果の出し方**が必要。
- 「構えているだけ」型は、持っている間だけ有効な効果（盾の防御面、視界の変化）。
- 両手持ち/片手持ちと「もう片方の手」の概念（C）は、装備枠の拡張で入るようにしておく。

| 接触 | 轢く、落下物、トラバサミ、有刺鉄線 | B |

**設計への要求**：届け方（どこに当たるかの決め方）と、届く中身（何が起きるか）を**分ける**。同じ「中身」を、弾・爆発・領域・接触のどれからでも使えるように。

## 問6. アイテムは「何ができる物」の組み合わせか／アイテムに何が起きるか

**できること（特性）**

| 特性 | 確度 | 特性 | 確度 |
|---|---|---|---|
| 重ねる | A | 中に物を入れる | A |
| 耐久 | A | 残量・回数 | A |
| 武器（銃/近接/投擲/設置） | A | 弾・弾倉 | A |
| 部品として付く／部品を付けられる | A | 防具 | A |
| 装備して効果 | A | 消費して効果 | A |
| 鍵・解錠具 | A | クエスト品 | A |
| 電池で動く（暗視・ライト・センサー・スタンバトン） | B | 切り替え状態を持つ（オン/オフ・畳む） | B |
| 拠点に置ける | B | 読める（メモ・地図・暗証番号） | B |
| 設計図（レシピを覚える） | B | 通貨そのもの | C |
| 時間で変化（腐る・冷める・充電される） | C | 着ると見た目・正体が変わる（変装） | C |
| 生き物（連れ歩く犬・伝書鳩） | × | ランダムな付与効果（接辞） | B（ルーター型で A） |

**アイテムに起きること（変換）**

| 変換 | 確度 |
|---|---|
| 作る（複数→1） / 分解する（1→複数） | A |
| 修理する / 充電する / 補充する | A / B / B |
| 部品を付け外しする | A |
| 改造して別物になる（切り詰め） | C |
| 開封する（箱→中身、弾薬箱→弾） | B |
| 調べて正体が分かる（未鑑定） | C |
| 強化する（レベルを上げる・接辞を付け直す） | B（ルーター型） |
| 壊れる・失う・保険で戻る | A |
| 合成する（同じ物3つ→上位） | C（ルーター型） |

**アイテムが存在しうる場所**

装備枠／グリッド収納（入れ子）／武器の中（薬室・弾倉・部品の台座）／床／世界の入れ物（箱・死体・金庫・隠し収納）／スタッシュ／商人の在庫／買い戻し／保険の返却待ち／クエスト報酬の受け取り箱／製作中／拠点に設置済み／手に持って投げている最中／刺さっている（回収できるボルト）／**レイドをまたいで残る隠し場所**（C）。

**設計への要求**
- 特性は足していける（今の設計どおり）。特性ごとの状態はセーブできること。
- 「変換」を共通の形（入力アイテム→出力アイテム、条件、時間）で表す。
- アイテムの居場所はどれも同じ「入れ物」の口で扱い、移動は必ず1つの操作として検証する。

## 問7. 能力値を持つのは誰か、補正はどこから来るか

**持ち主**：アクター（A）／武器（A）／防具・装備品（A）／乗り物（C）／拠点（B：施設の効果）／分隊（C）／レイド全体（B：難度・天候・イベントによる全員への補正）。

**補正の出所**：装備／部品／弾／状態異常／姿勢・行動（しゃがみ・構え・移動中）／スキル・特典／拠点の施設／興奮剤／負傷／重量／接辞／ラン内強化／天候・時間帯・明るさ／難度設定／モードの方針／デバッグ。

**設計への要求**：補正は必ず「出所」を持ち、出所ごとに外せる。**世界全体からの補正**（天候・難度）を全員の表へ流す口が要る。

## 問10. 世界の物への関わり方

**関わり方の型**：押す・開ける（即時）／長押し（時間）／選択肢から選ぶ／アイテムを使う／小さな操作を挟む（ピッキング・配線・暗証番号入力：B）／持って運ぶ（死体・燃料缶・重い箱：C）／押して動かす（遮蔽・台車：C）／乗る・着く（梯子・銃座・乗り物：B〜C）／乗り越える・くぐる（B）／壊す／撃って作動させる／近づくだけで起きる（罠・自動ドア・センサー）／話す（B）。

**世界の物の種類**：ドア・窓・シャッター・隔壁／箱・金庫・ロッカー・隠し収納／スイッチ・発電機・配電盤・端末／警報・カメラ・銃座／罠／照明／可燃物・爆発物／梯子・ロープ地点・エレベーター／脱出地点／クエスト用の地点／商人・会話相手／補給投下の箱／クレーンなどの大型装置。

**設計への要求**
- レベルデザイナーが「**これが起きたら、あれが起きる**」を組めること（スイッチ→扉、警報→増援、電源→銃座起動、ボス死亡→出口解放）。条件と効果を**共通の語彙**にして、脱出条件・クエスト目標・解放条件・会話の分岐と使い回す。
- 物の状態が変わると、経路・視線・音・光・AI の知識が追従すること。
- 物の状態の持続範囲：レイド中（A）／レイドをまたぐ（C：近道を開けたら次も開いている）／恒久（拠点）。

## 問17. 魔法は「何ができる」ものか

> エンジニア：魔法を銃の亜種として扱えるのか、別の仕組みが要るのかを決めたい。

**発動の仕方**

| 型 | 例 | 設計が吸収すべき点 |
|---|---|---|
| 即時 | 小さな火球、瞬間移動 | 入力→即発動 |
| 詠唱 | 大魔法 | 詠唱中は動きが制限、被弾・移動で中断、中断時に消費を返すか |
| 溜め | 溜めるほど威力・範囲・弾数が増える | 溜め量を効果へ渡す |
| 維持 | 押している間だけ出続ける光線・結界・浮遊 | 毎秒の消費、消費切れで終了 |
| 切替 | オーラ・変身・武器への属性付与 | オン中は上限や回復を占有 |
| 常時 | 覚えているだけで効く | 能力値補正・発動効果として扱う |
| 設置→時間差 | 魔法陣、時限の印 | 設置物・時間差の効果 |
| 連携 | 自分の置いた油に火、仲間の魔法と合体 | 反応の仕組み |

**届き方**：弾（直進・放物線・追尾・貫通・分裂・連鎖）／瞬間の形（扇・円・線）／残る領域（壁・床・霧）／光線／対象指定／自分／呼び出し。

**中身（ダメージ以外）**

| 種類 | 例 |
|---|---|
| 属性ダメージと付着 | 火（炎上）・氷（鈍足→凍結）・雷（感電・連鎖）・水（濡れ）・毒・風（吹き飛ばし）・土（壁）・光（目潰し）・闇（視界を奪う） |
| 反応 | 濡れ＋雷＝範囲感電／油＋火＝燃える床／凍結＋打撃＝砕ける／ガス＋火＝爆発／水＋氷＝凍った床で滑る／煙＋風＝晴れる |
| 移動 | 瞬間移動、位置の入れ替え、引き寄せ、吹き飛ばし、浮遊、壁抜け |
| 時間 | 全体を遅く、自分だけ速く、対象を止める |
| 知覚 | 透明化、音を消す、壁越しに見る、敵の位置を暴く、幻（おとり） |
| 物 | 念動で動かす・投げる、鍵を開ける、罠を解く、物を直す |
| 生死 | 回復、蘇生、吸収、呪い、死体を操る |
| 支配 | 操る、怯えさせる、眠らせる、敵対を解く |
| 変化 | 変身（別の体と能力になる）、巨大化・縮小、武器に属性を宿す |
| 呼び出し | 使い魔、精霊、壁、砲台、分身 |
| 打ち消し | 相手の魔法を消す、反射する、沈黙させる |

**環境との関係**：水たまり・油・ガス・草・木・金属の床など、**場所が属性の受け皿になる**。雨（天候）で全員が濡れる、夜は闇魔法が強い、など。

**設計への要求**
- 魔法専用の仕組みは作らない。**能力＝発動の仕方 × 消費 × 届き方 × 効果** の一般形で、銃の固有技・戦技・ガジェット・回避と同じ土俵に置く。
- 発動の仕方（即時/詠唱/溜め/維持/切替/常時）は「行動の区間の進め方の違い」。
- 属性は「付着（相手や場所に残る）」と「反応の表」。反応はダメージ計算の1段と、場所同士の反応の2か所で起こす。
- 効果の種類（瞬間移動・時間・透明・念動・変身・支配・蘇生・打ち消し）を、共通の効果として足していける。
- 呼び出した物は「持ち主の命令を受ける AI」＝仲間と同じ仕組み。
- **AI も同じ能力を使える**（敵の魔法使い、ボスの技）。

**組み合わせの爆発に対する方針**：修飾・発動効果・属性・反応は**全部が同じ「効果」と「タグ」の語彙**で繋がるので、個別の組み合わせを実装しない。制御はタグ（「この修飾は弾を飛ばす能力にだけ付く」）で行う。

| ロストとの関係 | 装備由来は死亡で失う／覚えた物は残る | モードの方針と整合（脱出型では装備由来が中心になる、など） |

## デザイナーからの提案：魔法・戦技をこのゲームにどう入れるか

「ルールは混ぜない」方針と、脱出型の緊張感（持ち物を賭ける）を崩さないための案。

| 案 | 内容 | 向くモード |
|---|---|---|
| **A. 遺物（レリック）方式** | 魔法・戦技は**装備品に宿る**。杖・指輪・古い武器を装備している間だけ使え、死ねば失う。触媒が弾薬の役割 | 脱出型（ロストの緊張と直結。「強い魔法＝高価な持ち物」） |
| **B. 習得方式** | 書物やツリーで覚えて枠にセット。死んでも失わない | ルーター型（育成の楽しさ） |
| **C. ラン内獲得方式** | ラン中に拾って組み合わせ、終われば消える。修飾の組み合わせでビルドを作る | ローグライト型（毎回違うビルド） |

推奨：**モードごとに A/B/C を使い分ける**。設計は3つとも「能力の出所」の違いとして同じ仕組みで扱えるので、追加コストは小さい。
属性と反応は、既にある環境要素（水・油・ガス・煙・火）と弾（焼夷弾・テーザー）をそのまま受け皿にできる。

## ヒアリング第4回の結果：ゲームの核の言い直し

クライアント（ディレクター）の言葉：
> ベースは脱出シューターだが、モード切替やステージごとの特徴としてルーターシューター的な要素が欲しい。シリアスにはしたいので、属性反応や環境利用ができるとリアル。
> 「脱出」は重要だが、魔法の世界観でシューティング要素と近接を混ぜることはできるから、**必ずしも銃である必要はなく、むしろ魔法を連射できる世界観である、とか、魔法を連射できる銃みたいな世界観でもいい**。

| 項目 | 確定したこと |
|---|---|
| 核 | **脱出**（持ち物を賭けて潜り、生きて帰る）。これは動かない |
| 戦闘 | 射撃と近接を混ぜる。**「銃」は必須ではなく「撃ち出す武器」**。魔法を連射する／魔法を撃ち出す銃 |
| 世界観 | **銃と魔法が同格**。シリアス |
| 手触りの拠り所 | 属性反応と環境利用（理屈が通ること＝リアルさ） |
| 参考の系統 | 脱出シューター＋ソウル系アクション＋ハクスラ系ビルド＋属性反応・環境利用 |
| ルーター要素 | モード／ステージの特徴として入れる |
| テンポ | ビルド次第で両立が理想。モードごとの色はあってよい |
| 追加の遊び | 拠点の防衛・襲撃 |

→ 02章の「一文」を改める案：**「魔法を撃ち、斬り結び、持ち物を賭けて潜って生きて帰る。属性と環境を読んだ者が勝つ見下ろし型の脱出アクション」**

## 問21. 「撃ち出す武器」はどこまで同じ仕組みで、どこが違うか

> エンジニア：発射方式・給弾・拡散・反動・部品という銃の仕組みを、魔法の武器にもそのまま使えるかを決めたい。

| 観点 | 実弾の銃 | 魔導銃（魔法を撃ち出す銃） | 杖・触媒 | 弓・投射器 |
|---|---|---|---|---|
| 発射方式 | セミ/バースト/フル/手動 | 同じ | 同じ＋溜め・維持 | 溜め |
| 撃つための資源 | 弾倉の弾 | 魔弾の弾倉 or 魔力セル | 持ち主の魔力／触媒 | 矢 |
| 再装填 | 弾倉交換・1発ずつ | 同じ／セル交換／自然回復 | 回復待ち・瞑想・触媒の交換 | 1本ずつ |
| 撃ち出される中身 | 弾（物理） | 属性つきの魔弾 | 魔法（弾・光線・領域） | 矢（回収可） |
| 中身の差し替え | 弾種（通常/貫通/軟頭） | 魔弾の種類（火/氷/雷/貫通/炸裂） | セットした魔法 | 矢の種類 |
| 拡散・反動 | あり | あり（魔力の暴れとして） | 小さい or なし | 溜め不足でぶれる |
| 過熱・暴発 | 故障 | 過熱・暴走（属性による自傷） | 詠唱失敗 | 弦切れ |
| 部品・埋め込み | アタッチメント | アタッチメント＋ルーン | 宝珠・芯・ルーン | 弦・照準具 |
| 音・光 | 銃声・発砲炎 | 属性ごとの音と光（雷は目立つ、氷は静か） | 同左 | 静か |
| 防具との相性 | 貫通力 対 防具クラス | 属性耐性 対 属性、結界 | 同左 | 貫通力 |

**デザイナーの結論**：4種は**同じ仕組み**でよい。違うのは「何を消費して」「何を撃ち出すか」だけ。
- 「弾薬」を **「装填物」**（実弾・魔弾・矢・触媒）と言い換え、属性・命中時の効果・弾の振る舞い（追尾・連鎖・分裂・着弾で領域）を持たせる。
- 給弾元に **「持ち主のリソース（魔力・熱・電池）から直接撃つ」** を追加する。
- 弾道の仕組み（貫通・跳弾・材質）は魔弾にも適用し、属性ごとに材質との相性を持たせる（雷は金属を伝う、火は木を燃やす、氷は水面を凍らせる）＝環境利用。
- 脱出型の緊張との相性：**魔弾・触媒は持ち物（賭ける物）**、魔力は「その場で回復する代わりに弱い/遅い」という天秤にできる。

**設計への要求**：銃の特性を「撃ち出す武器」の特性として一般化。装填物に「撃ち出される中身」を持たせ、弾の仕様へ属性と効果を載せる。リソースから撃つ給弾方式を追加。→ 反映済み

## 問22. 拠点の防衛・襲撃

| 決めること | 選択肢 | 仮置き |
|---|---|---|
| いつ起きるか | 拠点側の時間（レイド回数）／富の量に比例／物語の節目／予告あり・なし | 富に比例＋数レイド前に予告 |
| どう戦うか | 自分で防衛（拠点がマップになる）／留守番（設備と仲間に任せ、結果だけ出る）／選べる | 選べる |
| 守る手段 | 置いた設備（銃座・罠・壁・結界）、仲間、自分 | 配置カスタムと統合 |
| 負けると | 施設の損傷、スタッシュの一部を奪われる、商人が離れる | 施設の損傷＋通貨の一部 |

| 取り返す | 奪われた物を持つ敵がマップに現れる | 入りうる |
